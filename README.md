# Вебформа входу до інформаційної системи
Навчальний проєкт для лабораторних робіт з дисципліни «Технології програмування».
Форма реалізує авторизацію користувача з базовою валідацією полів засобами HTML5 та JavaScript.
## Як запустити проєкт
1. Склонуйте репозиторій.
2. Відкрийте файл `index.html` у будь-якому сучасному веббраузері (Chrome, Edge, Firefox).
